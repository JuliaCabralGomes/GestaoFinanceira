Gestão Financeira

Um dashboard de gestão financeira e controle operacional, desenvolvido para praticar manipulação de dados, persistência local, visualização de informações e interações dinâmicas com JavaScript.

Funcionalidades

Cadastro de receitas e despesas
Cálculo automático de receitas, despesas e saldo operacional
Persistência das transações utilizando localStorage
Pesquisa por descrição ou categoria
Filtro por tipo de operação
Exclusão de transações
Gráfico de distribuição entre receitas e despesas com Chart.js
Exportação das transações para CSV
Atualização dinâmica dos indicadores e da tabela
Interface responsiva para diferentes tamanhos de tela
Tratamento de estados sem resultados na pesquisa ou filtragem

Tecnologias

HTML, CSS e JavaScript puros
[Chart.js](https://www.chartjs.org/) - biblioteca utilizada para visualização dos dados financeiros
localStorage - persistência dos dados no navegador

Conceitos praticados

Esse projeto foi construído como parte de uma trilha de aprendizado, com foco em lógica de programação, manipulação do DOM e organização de dados:

Manipulação e atualização dinâmica do DOM
Arrays, objetos, filter() e reduce()
Eventos de formulário e interação com elementos da interface
Persistência de dados com localStorage
Criação e atualização de gráficos com Chart.js
Pesquisa e filtragem de dados em tempo real
Geração e exportação de arquivos CSV
Validação de dados inseridos pelo usuário
Tratamento de conteúdo inserido na interface com escape de HTML
Organização de funções e responsabilidades no JavaScript
Desenvolvimento de interfaces responsivas

Como rodar

1. Clone este repositório
2. Abra o projeto no VS Code
3. Execute utilizando um servidor local, como o Live Server
4. Acesse o index.html pelo servidor
